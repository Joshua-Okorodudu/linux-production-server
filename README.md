# Enterprise Linux Server

## 📖 Project Overview

This project documents the deployment and configuration of a production-style Ubuntu Server.

The goal is to demonstrate practical Linux Systems Administration skills through hands-on implementation of server deployment, Linux administration, networking, security hardening, automation, web server configuration, monitoring, and documentation.

---

## 🎯 Objectives

- Deploy Ubuntu Server
- Configure Linux users and groups
- Secure SSH access
- Configure the UFW firewall
- Install and configure NGINX
- Automate administrative tasks using Bash
- Monitor server health
- Document every stage of the project

---

## 🛠️ Technologies

- Ubuntu Server

- VirtualBox
- SSH
