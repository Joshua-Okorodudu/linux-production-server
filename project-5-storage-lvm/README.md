# Project 05 – Storage & LVM

## Objective

Configure and manage Linux storage using Logical Volume Management (LVM).

## Completed

- Inspected existing disks and LVM configuration
- Created a 5 GB logical volume
- Formatted the logical volume with ext4
- Created and configured a mount point
- Configured persistent mounting using `/etc/fstab`
- Verified the logical volume and filesystem
- Verified the persistent mount configuration

## Result

Successfully created and mounted a dedicated LVM logical volume on Ubuntu Server and configured it to persist across reboots.

## Technologies

- Ubuntu Server
- LVM
- ext4
- `/etc/fstab`
- Linux storage management
